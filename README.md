### Двухэтапное детектирование переплёта со средником

Проект решает задачу выявления старинных переплётных крышек, на которых присутствует *средник* — центральный декоративный элемент, являющийся центром декоративной композиции крышки.

Работает в два этапа:

1. **ConvNeXt-Tiny** (ансамбль из 5 фолдов) — определяет, является ли изображение переплётом (переплёт / не переплёт).
2. **DINOv2 ViT-Small** (ансамбль из 5 фолдов + TTA) — на найденных переплётах проверяет наличие средника (со средником / без средника).

На выходе можно либо разметить уже скачанные изображения, либо в реальном времени скачивать и фильтровать переплёты со средником с сайта рукописного фонда.

Веса моделей: **<https://huggingface.co/Infarondus/Klein-marchen_Base>**

## Результаты

Все метрики — out-of-fold: каждое изображение оценивается моделью, не видевшей его при обучении.

| | Accuracy | F1-macro |
| --- | --- | --- |
| Этап 1, ConvNeXt (1614 изобр., группировка по рукописи) | 0.988 | 0.986 |
| Этап 2, DINOv2 (1136 изобр.) | 0.929 | 0.929 |

Перенос этапа 2 на фонд, исключённый из обучения: фонд 98 — AUC 0.942, фонд 304-I — AUC 0.979.

**Сквозная проверка на независимом фонде 228 РГБ** (219 рукописей, ручная проверка вслепую): точность отбора **0.989** (89 из 90), полнота **0.840** (89 из 106).

Исходные данные всех оценок — в папке `results/`. Подробности — в карточке модели на Hugging Face.

> **Ноябрь 2026.** Прежние метрики (ConvNeXt F1 0.914, DINOv2 F1 0.937) были получены на изображениях, пересекавшихся с обучающими, и заменены приведёнными выше. Модель первого этапа заменена ансамблем из 5 моделей; модели второго этапа не менялись.

## Структура репозитория

```bash
.
├── deep_test_v2.py            # рецепт обучения ConvNeXt (переплёт / не переплёт)
├── deep_test_v4_dino.py       # обучение DINOv2 (средник / без средника), 5 фолдов
├── convnext_oof.py            # обучение ConvNeXt в 5 фолдах + OOF-оценка
├── dino_oof.py                # OOF-оценка DINOv2 по сохранённым фолдам
├── dino_leave_fond_out.py     # проверка DINOv2 на фонде, исключённом из обучения
├── scrape_bindings_v3.py      # скачивание + двухэтапная фильтрация (актуальная версия)

├── inspect_convnext.py        # какие слои ConvNeXt изменились при обучении
├── inference.py               # разметка папки изображений (этап 2)
├── results/                   # CSV с результатами всех оценок
└── legacy/
    ├── scrape_bindings_v2.py  # прежняя версия скрапера (одна модель ConvNeXt)
    └── evaluate.py            # прежняя оценка DINOv2 — см. «Важные замечания»
```

## Обучение и оценка

### 1. ConvNeXt-Tiny — детектор переплёта

**Вход:** папки `./binding` и `./not_binding`.

```bash
python convnext_oof.py              # все данные        -> models_oof_full/
python convnext_oof.py --balanced   # классы поровну     -> models_oof_balanced/
```

Скрипт обучает 5 фолдов рецептом из `deep_test_v2.py` (три фазы с постепенной разморозкой, лучшая модель выбирается по валидационному F1), удаляет дубли, группирует снимки одной рукописи в один фолд и выводит OOF-метрики. Модели для пайплайна — `models_oof_full/fold_*_oof.pth`.

### 2. DINOv2 ViT-Small — детектор средника

**Вход:** папки `./selected` (со средником) и `./rejected` (без средника).

```bash
python deep_test_v4_dino.py     # обучение 5 фолдов -> models/fold_*_dinov2.pth
python dino_oof.py              # OOF-оценка (самопроверка совпадения разбиения с обучением)
python dino_leave_fond_out.py --fond 98     # обучение без фонда 98 и проверка на нём
```

Модели на Hugging Face названы `fold_*_km.pth`; это те же файлы, что создаёт `deep_test_v4_dino.py`.

## Скрапинг с фильтрацией

```bash
python scrape_bindings_v3.py
```

Номер фонда и пороги задаются в начале файла. Все модели (5 ConvNeXt + 5 DINOv2) кладутся в одну папку `models_pipeline/`; тип модели определяется автоматически.

Для каждой рукописи скрипт проверяет первые 5 снимков, выбирает лучший по оценке ConvNeXt (порог τ₁ = 0.60) и проверяет его на средник (τ₂ = 0.55). Результаты раскладываются в `run_fond_<N>/`:

- `1_со_средником/` — итог;
- `2_отклонено_по_среднику/` и `3_переплёт_не_найден/` — отклонённые снимки (для оценки полноты);
- `log.csv` — оценки по каждой рукописи; `run_info.json` — параметры запуска и контрольные суммы моделей.

Проверка результатов:

```bash
python review_run.py ./run_fond_228   # клавиши 1–4, затем отчёт
```

## Важные замечания

- `legacy/evaluate.py` прогоняет ансамбль всех пяти фолдов по всему датасету, т.е. по изображениям, на которых часть моделей обучалась; его результаты завышены. Для оценки используйте `dino_oof.py`.
- Порог τ₂ подобран на данных обучающих фондов. На новых коллекциях шкала уверенности смещается — порог стоит откалибровать на небольшой размеченной выборке.
- Разметка выполнена одним автором. Класс «со средником»: центральный элемент является центром декоративной композиции (тиснёный средник или металлическая накладка в окружении орнамента); одиночная накладка на гладкой крышке средником не считается.
- Обучение проводилось на GPU NVIDIA RTX 4050 Laptop (6 GB) и RTX 5060 Ti (16 GB).
- Пути к папкам заданы в начале каждого скрипта — поправьте их под своё расположение файлов.
- Архитектурные решения и код были реализованы при помощи инструментов генеративного искусственного интеллекта Claude, Anthropic.
