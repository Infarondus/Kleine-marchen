# Рукописный переплёт со средником — двухэтапное детектирование

Проект решает задачу выявления старинных переплётных крышек, на которых присутствует **средник** (центральный декоративный элемент).  
Работает в два этапа:

1. **ConvNeXt Tiny** – определяет, является ли изображение переплётом (binding / not binding).  
2. **DINOv2 ViT‑Small** (ансамбль из 5 фолдов) – на переплётах, найденных первым этапом, проверяет наличие средника (со средником / без средника).

На выходе можно либо разметить уже скачанные изображения, либо в реальном времени выкачать и отфильтровать переплёты со средником с сайта рукописного фонда.

---

## Структура репозитория

```
.
├── deep_test_v4_dino.py       # обучение DINOv2 (средник/без средника)
├── deep_test_v2.py            # обучение ConvNeXt (переплёт/не переплёт) – устаревший/неоптимальный
├── evaluate.py                # оценка ансамбля DINOv2 на всём датасете
├── inference.py               # разметка неразмеченных переплётов через DINOv2
├── scrape_bindings_v2.py      # скачивание + двухэтапная фильтрация на лету
├── models/                    # папка с обученными моделями DINOv2 (fold_*_dinov2.pth)
├── data/raw/models/           # ожидаемое место для ConvNeXt‑модели (binding_model.pth)
│
├── selected/                  # (для обучения) переплёты со средником
├── rejected/                  # (для обучения) переплёты без средника
├── binding/                   # (для ConvNeXt) изображения переплётов
├── not_binding/               # (для ConvNeXt) изображения НЕ переплётов
│
├── eval_results/              # результаты evaluate.py
├── result/                    # результаты inference.py
└── images/bindings_srednik/   # сохранённые переплёты со средником (scrape)
```

*Папки `selected`, `rejected`, `binding`, `not_binding` нужно создать самостоятельно и наполнить данными для обучения.*

## Обучение моделей

### 1. ConvNeXt – детектор переплёта

**Скрипт:** `deep_test_v2.py`  
**Входные папки:** `./binding` (переплёты) и `./not_binding` (не переплёты).  
**Особенность:** Экспериментально выяснилось, что полная или частичная разморозка backbone разрушает качество. Рабочий вариант – **обучение только классифицирующей головы** (фаза 1 скрипта). Именно модель, полученная после фазы 1, используется в дальнейшем.

**Запуск (не обязателен, если уже есть готовая модель):**
```bash
python deep_test_v2.py
```
Лучшая модель сохранится в `models/fold_*_best.pth`. Для использования в пайплайне её нужно скопировать в `./data/raw/models/binding_model.pth`.

*Примечание:* Если вы не планируете дообучать детектор переплёта, достаточно иметь один файл `binding_model.pth`, полученный после фазы 1 этого скрипта.

### 2. DINOv2 – детектор средника

**Скрипт:** `deep_test_v4_dino.py`  
**Входные папки:** `./selected` (со средником) и `./rejected` (без средника).  
**Модель:** `vit_small_patch14_dinov2.lvd142m` (21M параметров).  
**Стратегия:** двухфазное обучение – сначала только MLP‑голова, затем совместное дообучение последних 4 блоков трансформера с дифференцированным learning rate. Используются EMA, TTA, взвешенный семплер, label smoothing.

**Запуск:**
```bash
python deep_test_v4_dino.py
```
Результат: в папку `models/` сохранятся 5 файлов `fold_1_dinov2.pth … fold_5_dinov2.pth` (по числу фолдов). Они необходимы для всех последующих скриптов.

## Оценка DINOv2 на датасете

**Скрипт:** `evaluate.py`  
**Вход:** папки `selected`, `rejected` и модели `models/fold_*_dinov2.pth`.  
**Что делает:**  
- Прогоняет все изображения через ансамбль из 5 фолдов с TTA (5 трансформаций).  
- Выводит accuracy, F1‑macro, precision, recall, матрицу ошибок.  
- Копирует ошибочно классифицированные и сомнительные (confidence < 0.7) изображения в папку `eval_results/` для ручного просмотра.

**Запуск:**
```bash
python evaluate.py
```

## Инференс – разметка незнакомых переплётов

**Скрипт:** `inference.py`  
**Вход:** папка с неразмеченными изображениями (по умолчанию `./training_option`).  
**Что делает:**  
- Использует ансамбль DINOv2 и TTA.  
- Раскладывает изображения по трём папкам внутри `./result/`:
  - `со_средником/` – уверенность ≥ порога,
  - `без_средника/` – уверенность отсутствия ≥ порога,
  - `сомнительные/` – модель не уверена (нужен ручной просмотр).

Порог уверенности можно задать аргументом `--threshold` (по умолчанию 0.75).

**Запуск:**
```bash
python inference.py --input путь/к/фото --threshold 0.8
```

## Скрапинг с фильтрацией в реальном времени

**Скрипт:** `scrape_bindings_v2.py`  
**Использует обе модели последовательно.**  
**Логика для каждой рукописи:**
1. Selenium собирает первые N изображений с карточки рукописи (lib‑fond.ru).
2. ConvNeXt отбирает лучший переплёт (score ≥ `BINDING_MIN_SCORE`).
3. На отобранном переплёте DINOv2 проверяет наличие средника (score ≥ `SREDNIK_MIN_SCORE`).
4. Если оба условия выполнены – изображение сохраняется в `images/bindings_srednik/`.

**Требования:**  
- Рядом со скриптом должен лежать `msedgedriver.exe` (либо замените драйвер в коде).  
- Путь к ConvNeXt‑модели: `./data/raw/models/binding_model.pth`.  
- Путь к DINOv2‑моделям: в коде прописан `./kleine-marchen/models` – при необходимости измените на `./models`.

**Запуск:**
```bash
python scrape_bindings_v2.py
```

Настройки (коллекция, пороги, количество проверяемых изображений) задаются в начале скрипта.

## Замечания

- Модель ConvNeXt (`deep_test_v2.py`) в текущем виде **не приспособлена** для полноценного fine‑tuning’а – разморозка слоёв приводила к деградации. Поэтому если вы захотите обучить свой детектор переплёта «с нуля», ограничьтесь фазой 1 этого скрипта (обучение только головы).
- DINOv2‑пайплайн (`deep_test_v4_dino.py`) стабильно работает и даёт высокие метрики. Его обучение рекомендуется на GPU с ≥6 ГБ VRAM (batch size 32 при 280px).
- Все скрипты, работающие с DINOv2, ожидают найти модели в папке `models/` с именами `fold_*_dinov2.pth`. Убедитесь, что файлы именно такие.
- Для работы `scrape_bindings_v2.py` требуется стабильный интернет и установленный браузерный драйвер. При проблемах с Selenium можно заменить его на другой метод получения прямых ссылок, но стандартный перебор номеров DSC‑файлов работает только если структура URL предсказуема.
